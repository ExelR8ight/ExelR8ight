## 🏆 Featured Portfolio Projects

### 🧠 [CogniSOC: End-to-End AI-Powered SOC Architecture](https://github.com/ExelR8ight/CogniSOC)
My flagship project. A complete, production-ready SOC pipeline built from scratch. It ingests raw telemetry from an isolated lab environment, runs an **Isolation Forest** anomaly detection model in Python to catch behavioral outliers, correlates them via a custom rule engine, and automates case escalation to **TheHive**. 
- *Achieved an 88% Precision rate and reduced alert fatigue by 75% compared to a baseline rule-only system.*

### 🛡️ [ATT&CK-Mapped Detection Library](https://github.com/ExelR8ight/ATT-CK-Detection-Library)
A version-controlled "Detection-as-Code" repository. Contains 13 highly tuned **Sigma** rules mapped across 6 MITRE ATT&CK tactics. Every rule is validated using **Atomic Red Team** and includes explicit false-positive tuning notes to demonstrate real-world SOC maturity. Includes ready-to-deploy **Splunk SPL** and **Elastic Query DSL** translations.

### 🔍 [Threat Hunting & Incident Investigation Lab](https://github.com/ExelR8ight/Threat-Hunting-Lab)
A collection of 7 structured, end-to-end incident investigations mimicking real-world APT tradecraft (like APT29 and FIN7). Features deep-dive analyses into Data Exfiltration, PowerShell Empire C2 beacons, Lateral Movement, and Credential Dumping. Complete with extracted IOCs and custom incident response playbooks.
